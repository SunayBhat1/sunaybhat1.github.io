How the committee worked

Timing

    Information diet

    All agents see the same alphabetized candidate list, compact game rows, team résumés, and available ratings. The four conditions cross prior CFP and AP visibility. Poll-off conditions omit the relevant poll table and résumé rank fields. Polls help define the candidate pool before the experiment, so that eligibility stays the same across conditions.

    Leakage controls

    The runner verifies the frozen packet SHA-256 and date cutoffs before calling models. Packet-only voters see the frozen evidence. The two research committees also use live search from specified domains. The input packet predates the target CFP release. Prior CFP publication date is a configured mapping because the source has no timestamp. Prompt instructions cannot erase knowledge already in model weights.

    Final council review

    GPT-6.2 Sol, Claude Sonnet 5.5, and Gemini 4 Hydrogen each reviewed the same evidence and the 14 member ballots for each committee. They made independent proposals, read the other two proposals without model names, and each revised once. Direct game winners and comparison decisions were checked against the frozen scores and the submitted rankings. The council used the original evidence and recorded research, with no new searches.

    Each revised ballot gets one vote. For every pair of teams, the tally locks the stronger majorities first and skips comparisons that would create a cycle. Equal-strength priorities use the original poll order. The data download includes both rounds.

    Model Polls

    Each ballot ranks exactly 25 unique eligible teams and explains its top 12. A committee needs at least 10 valid ballots. Borda awards 25 points for first through 1 for 25th, breaking ties on available SP+ then alphabetically. Persona contrasts are descriptive.

    Committee types

    Combined committee
    Different AI models fill fixed seats on one committee. Every seat has its own voting style. Model assignments stay the same across the poll settings.
    Combined committee · second vote
    The same models and seats vote again from scratch. Models that support a creativity setting get a higher setting on this vote.
    Single-model committee
    Every seat uses one AI model with different voting styles across seats. Historical runs included these committees to compare how the models rank the same teams.

    The voting styles

    Each voter got a different emphasis, such as efficiency, quality of wins, or head-to-head results.
